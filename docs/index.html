Claude Critter: a Tokenless Desktop Pet for the Claude Desktop App (Windows)

A tiny desktop pet that lives in the Claude desktop app, reacts to everything Claude does and never costs a token.

View on GitHubVideo on YouTubeDocumentation

Claude Critter is a free desktop pet for the Claude desktop app on Windows. It reacts to Claude's tools, permission prompts, tests, commits and subagents. Zero tokens, no screenshots, a Claude Code plugin.

Features

Works along with Claude

A book while Claude reads, a magnifier while it searches, a pencil while it edits.

Waits with you

Holds up a sign at permission prompts and cheers when you allow.

Celebrates

Dances when tests pass and throws confetti on commits.

Has coworkers

Every subagent walks in as a small critter.

Platformer UI

Messages, code blocks and the prompt box are platforms. Pet it, throw it, play fetch.

Zero tokens, no screenshots

Never calls a model; reads the window with Windows UI Automation. Nothing leaves your PC.
